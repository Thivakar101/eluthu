# Security

Eluthu processes handwriting images locally in the browser. Please avoid posting private project JSON or handwriting photos in public issues.

If you find a vulnerability, use GitHub's **Report a vulnerability** option in the repository's Security tab when available. Include a minimal reproduction and affected version. If private reporting is unavailable, open an issue asking maintainers for a private contact channel without disclosing exploit details.

Supported version: the current `main` branch.
